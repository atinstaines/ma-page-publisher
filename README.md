# MA Page Publisher - policy website

Free static website for use with Meta Developer app settings.

## Before publishing (important)

These are draft disclosures based on an assumed Facebook Page publishing workflow, not a verified audit of your application. Review each page against your actual implementation, especially where API tokens, media files, logs or account information are stored, which third-party tools receive data, and your real retention practices. Edit any inaccurate statements before publishing. The contact email below is copied from the Meta screenshot.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository called `ma-page-publisher`.
2. Upload the contents of this ZIP (not the containing folder) to the repository root and commit.
3. In the repository select **Settings → Pages**.
4. Under **Build and deployment** select **Deploy from a branch**, choose `main` and `/(root)`, then **Save**.
5. When the deployment completes, open each link in a private/incognito window.

Replace `YOURUSERNAME` below with your actual GitHub username:

- Privacy policy: `https://YOURUSERNAME.github.io/ma-page-publisher/privacy.html`
- Terms: `https://YOURUSERNAME.github.io/ma-page-publisher/terms.html`
- Data deletion: `https://YOURUSERNAME.github.io/ma-page-publisher/deletion.html`

Paste the three **real, live HTTPS links** into Meta Developers → App settings → Basic. Select the data deletion URL option if provided. Fill in category and any other required fields, save, then visit Publish to review any remaining access/review requirements.

**Important:** Publishing policies does NOT automatically publish the Meta app, grant API permissions, or make existing Facebook Reels public.
